# Variables para mastersaws-sites (solo IaC)

## Únicas variables obligatorias

| Variable | Descripción |
|---|---|
| `AWS_ACCESS_KEY_ID` | Access key IAM (cuenta 941751053509) |
| `AWS_SECRET_ACCESS_KEY` | Secret key IAM |

**No necesitas** `PROD_S3_BUCKET`, `PROD_CLOUDFRONT_DISTRIBUTION_ID` ni similares.
El bucket y CloudFront se crean solos por CloudFormation.

## Cómo desplegar

**Actions → Deploy all → Run workflow → prod**

Un solo clic hace:
1. Crea bucket S3 + CloudFront (IaC)
2. Sube los 8 sitios
3. Invalida caché

Los nombres los genera la plantilla:
- Bucket: `mastersaws-portfolio-prod`
- Stack:  `mastersaws-portfolio-prod`

## Workflows disponibles

| Workflow | Cuándo usarlo |
|---|---|
| **Deploy all** | Primera vez y despliegues completos (recomendado) |
| Deploy infrastructure | Solo crear/actualizar S3 + CloudFront |
| Deploy content | Solo subir sitios (después de que IaC ya exista) |

## Región

`us-east-1` (fija en todos los workflows)
