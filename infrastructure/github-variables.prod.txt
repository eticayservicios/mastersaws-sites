# Variables para eticayservicios/mastersaws-sites
# GitHub → Settings → Secrets and variables → Actions

## Ya las tienes (credenciales)
| Variable | Obligatoria |
|---|---|
| AWS_ACCESS_KEY_ID | Sí |
| AWS_SECRET_ACCESS_KEY | Sí |

## Te faltan para prod (elige UNA opción)

### Opción A — Crear infra automáticamente (recomendado)
Ejecuta: Actions → Deploy infrastructure → prod
No necesitas más variables; el stack crea bucket y CloudFront.

### Opción B — Usar bucket/CloudFront existentes (como finops)
Agrega estas Variables en GitHub:

| Variable | Descripción | Dónde obtenerla |
|---|---|---|
| PROD_S3_BUCKET | Nombre del bucket S3 | AWS Console → S3 |
| PROD_CLOUDFRONT_DISTRIBUTION_ID | ID de CloudFront (empieza con E) | AWS Console → CloudFront |

Para dev, usa:
| Variable | Descripción |
|---|---|
| DEV_S3_BUCKET | Bucket de desarrollo |
| DEV_CLOUDFRONT_DISTRIBUTION_ID | CloudFront de desarrollo |

### Opción C — Nombres genéricos (monorepo)
| Variable | Descripción |
|---|---|
| S3_BUCKET | Bucket único |
| CLOUDFRONT_DISTRIBUTION_ID | CloudFront único |

## Cómo obtener el CloudFront ID
AWS Console → CloudFront → tu distribución → copia el ID (ej. E28J1Q8T8ACP4L)

## Región
Todos los workflows usan us-east-1
